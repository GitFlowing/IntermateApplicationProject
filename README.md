# Case Study Instagram Reels

This is a case study of randomized Instagram Reels (IG Reels) data. A dashboard is created to view KPIs and to visualize the data.
The dashboard shows different KPIs like number of likes, number of comments, number of views, number of plays or engagement rate.
For the visualization of the data the data is grouped in Influencer ID, Influencer type or date. The dashboard is available under:

https://intermate-case-study.streamlit.app/
